# Hands-Free Autonomous Cart 🚀

## Overview
The **Hands-Free Autonomous Cart** is a prototype product design developed to improve mobility in crowded public environments such as airports, malls, and transport hubs.  
The system is designed to automatically **follow a user while carrying luggage**, reducing the physical effort required to transport heavy items.

The project focuses on **user-centered design, sensor-based navigation, and feasibility analysis** for potential real-world deployment.

---

## Problem Statement
Transporting luggage in crowded public spaces can be physically demanding, especially for:
- Elderly individuals
- People with disabilities
- Travelers carrying heavy bags
- Patients or individuals with mobility limitations

Traditional carts require manual control and lack intelligent navigation capabilities.

---

## Proposed Solution
The **Hands-Free Autonomous Cart** introduces a smart navigation system that:

- Automatically follows the user
- Detects and avoids obstacles
- Tracks location using GPS
- Sends alerts through GSM communication
- Provides a safe and convenient luggage transport solution

---

## Key Features
- Autonomous user-following mechanism
- Obstacle detection using **Ultrasonic and IR sensors**
- Real-time tracking through **GPS module**
- Remote alerts via **GSM communication**
- Secure luggage compartment with safety alerts
- Designed for **crowded public environments**

---

## System Architecture
Main system components include:

- **Arduino-based control system**
- Ultrasonic sensors for distance measurement
- IR sensors for obstacle detection
- GPS module for location tracking
- GSM module for communication
- DC motors for cart movement
- Battery and power management system

---

## Product Design Methodology
The project applied structured **product development and design methodologies**, including:

- **TRIZ** – Inventive problem-solving framework
- **SCAMPER** – Idea generation technique
- **Benchmarking Matrix** – Concept evaluation and selection
- **Iterative Prototyping** – Refining product design based on analysis

Concept evaluation resulted in selecting the **most feasible design prototype** based on durability, security, cost, portability, and usability.
